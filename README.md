# Topological Data Analysis of Chicago Crime Patterns

Portfolio project applying Topological Data Analysis (TDA) to explore temporal and spatial patterns in Chicago crime data, with emphasis on Mapper graphs, community-level trajectories, and socioeconomic context from ACS variables.

## Project Overview

This project studies how crime composition and community-level patterns changed across pre-COVID, COVID, and post-COVID periods in Chicago. The analysis combines:

- Chicago crime incident records.
- Chicago community area boundaries.
- ACS socioeconomic indicators aggregated at the community-area level.
- Mapper-based topological summaries.
- Interactive Plotly visualizations and final report materials.

The core analysis is contained in the notebooks and the generated outputs are included under `outputs/`.

## Notebooks

- `notebooks/00_acs_data_preparation.ipynb`: Downloads ACS variables and prepares community-level socioeconomic features.
- `notebooks/01_tda_chicago_crime_overall.ipynb`: Main citywide/community-area TDA analysis.
- `notebooks/02_tda_chicago_crime_focused_26_communities.ipynb`: Focused analysis for the 26 selected communities discussed in the final report.

## Data

The full crime dataset is large and should not be committed to GitHub. Place local data files in `data/` before running the notebooks.

Expected local inputs include:

- `data/Crimes_-_2001_to_Present_20260401.csv`
- `data/Boundaries_-_Community_Areas_20260506.geojson`
- `data/ACS_ChicagoFeatures_2019_2023.csv`, generated by `00_acs_data_preparation.ipynb`

The crime data can be downloaded from the City of Chicago Data Portal, and ACS variables are retrieved from Census API workflows in the notebook.

## Outputs

Key generated artifacts are stored in:

- `outputs/`
- `report/TDA_FinalReport_fv.pdf`
- `report/TDA_FinalPresentation_fv.pdf`

The output folder contains interactive HTML visualizations, Mapper summaries, transition tables, volatility analysis, and final conclusion plots.

## Environment Setup

Create and activate a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Then open the notebooks:

```bash
jupyter lab
```

## Running in Colab or Locally

Each notebook starts with a portable path-configuration cell. In Colab, it mounts Google Drive and uses:

```text
/content/drive/MyDrive/tda_crime
```

Locally, it uses the repository root as `PROJECT_ROOT`. The notebooks look first under `data/`, then fall back to files placed directly in `PROJECT_ROOT`, which preserves compatibility with the original Colab layout.

## Reproducibility Notes

The analysis was originally developed from VS Code connected to Google Colab, with outputs written to Google Drive. The current notebooks keep that workflow supported while also allowing local execution from this repository.

Large raw data files and local notebook checkpoints are excluded from version control through `.gitignore`.
